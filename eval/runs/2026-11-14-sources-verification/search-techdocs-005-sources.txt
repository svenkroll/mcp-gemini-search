The documentation describes it as: > *"Remove a single stashed state from the stash list and apply it on top of the current working tree state, i.e., do the inverse operation of `git stash push`."*  **Primary Source of Truth:** * Official Git Reference Manual: [git-stash Documentation (git-scm.com)](https://git-scm.com/docs/git-stash)
