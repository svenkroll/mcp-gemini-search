  According to the Python documentation of built-in functions, `len()` returns the **length (the number of items) of an object**.   The argument passed to it may be a sequence (such as a string, bytes, tuple, list, or range) or a collection (such as a dictionary, set, or frozen set).  * **Primary Source of Truth:** Python Software Foundation, *The Python Standard Library — Built-in Functions (`len`)*: [https://docs.python.org/3/library/functions.html#len](https://docs.python.org/3/library/functions.html#len) (or for version 3.14: `https://docs.python.org/3.14/library/functions.html#len`).
